# Pizza Cashier – Windows Forms (C#)

Author: Bohdan Rusakov (Богдан Русаков), F117156, NBU

A simple cashier program for a pizza place - you build an order and it calculates the bill.

Features:
- choose a pizza from the list
- choose size (small, medium +25%, family +50%)
- extras, 1.55 eur each
- quantity
- 25% discount when an item is over 40 eur
- summary of the whole order

How to run: open PizzaCashier.slnx in Visual Studio (.NET 8) and press F5.
